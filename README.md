# AMIR Middle East Grill — Website Concept

Custom-coded, mobile-first website concept for **AMIR Middle East Grill** in St. Catharines, Ontario.

## Business details used

- **Address:** 185 Queenston St, St. Catharines, ON L2R 3A3
- **Phone:** +1 289-362-1717
- **Instagram:** https://www.instagram.com/amirmiddleeastgrill/
- **Hours used for concept:** Mon–Sat 11:00 AM–12:00 AM; Sun 2:00 PM–12:00 AM
- **Ordering:** Uber Eats and SkipTheDishes public listings

## What is built

- Responsive one-page restaurant experience
- Mobile navigation and sticky quick actions
- Popular menu preview
- Click-to-call, directions and ordering CTAs
- Instagram integration
- Local SEO title/meta structure
- `Restaurant` schema.org JSON-LD
- Semantic heading structure and FAQ content
- Accessible navigation and reduced-motion support
- Live open/closed status calculated in the Toronto time zone

## Important

This repository is a **client concept preview**, not the restaurant's official website yet. Public menu prices and business details should be reconfirmed with the restaurant before production launch.

The generic/demo visual assets should be replaced with restaurant-owned photography supplied or approved by AMIR before final production use.
